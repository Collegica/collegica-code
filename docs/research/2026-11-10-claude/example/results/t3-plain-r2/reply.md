The five minutes files in `notes/` now share one naming pattern, `YYYY-MM-DD-minutes.md`, so they sort by meeting date, and there is a new `notes/index.md` listing them.

| Old name | New name |
|---|---|
| `Meeting sept 8.md` | `2026-09-08-minutes.md` |
| `notes_2026-09-22.md` | `2026-09-22-minutes.md` |
| `oct6 meeting notes.md` | `2026-10-06-minutes.md` |
| `2026.10.20 minutes.md` | `2026-10-20-minutes.md` |
| `Nov 3 (final).md` | `2026-11-03-minutes.md` |

The index is a table with each meeting's date, a link to its file, and a one-line list of topics covered. File contents are unchanged, as are `README.md` and `members.csv`.

The "(final)" label on the 3 November file is gone from the name; say if you want it kept somewhere.
