# What to check each month

For the monthly check: read each address, compare against the guide's
"Last checked" line, and list what moved. The guide's volatile facts are all
in its section *The moving parts*.

| What | Address | What would change the guide |
|---|---|---|
| Claude apps release notes | <https://support.claude.com/en/articles/12138966-release-notes> | A new model, a plan change, memory or projects changing |
| Claude Code changelog | <https://code.claude.com/docs/en/changelog> (Markdown: add `.md`) | New default model, permission-mode changes, `CLAUDE.md` or `AGENTS.md` handling |
| Pricing | <https://claude.com/pricing> | Prices, plan names, what Free includes, the "Model training" row |
| Default model and effort | <https://code.claude.com/docs/en/model-config.md>, section "`default` model setting" | Which model a new subscriber gets |
| Best practices | <https://code.claude.com/docs/en/best-practices.md>, especially "What you can stop doing" | A practice the guide recommends being retired |
| Instruction file | <https://code.claude.com/docs/en/memory.md> | Where `CLAUDE.md` lives, size advice, `AGENTS.md` |
| Data use | <https://code.claude.com/docs/en/data-usage.md>; <https://privacy.claude.com/en/articles/10023580-is-my-data-used-for-model-training>; <https://privacy.claude.com/en/articles/10023548-how-long-do-you-store-my-data> | Training default, retention periods |
| Memory | <https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context> | Defaults, where the switches are |
| Projects | <https://support.claude.com/en/articles/9517075-what-are-projects> | The new projects (beta) reaching chat; Free plan limit |
| Anthropic news | <https://www.anthropic.com/news> (not read for this guide) | Model launches before the release notes catch up |

The support pages carry an "Updated" line; the privacy pages carry a date.
The Claude Code pages have none, so compare the text.
