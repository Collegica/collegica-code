## Projects

- Web: "Use a project to keep related chats, files, instructions, and
  sources together." "Project instructions apply across its chats." "A
  ChatGPT project doesn't provide direct access to a folder on your
  computer, so upload or connect the sources you want ChatGPT to use."
- Desktop app: "The **Projects** view in the ChatGPT desktop app includes
  ChatGPT projects and local projects that connect to folders on your
  computer." "A local project gives chats access to one or more folders on
  your computer". "ChatGPT can read and change files in every attached
  folder." The primary folder is where "Codex also uses that folder as the
  default for Git operations and automatic discovery of `AGENTS.md`".
- CLI: "Codex CLI treats the directory where you start it as the project for
  the chat." "The CLI doesn't expose the ChatGPT Projects view." "Keep
  durable project guidance in `AGENTS.md` or checked-in documentation so it
  is available to future chats."
- "Start a separate chat for each distinct outcome".

## Custom instructions

*Personalize*: "Use custom instructions for preferences you want ChatGPT to
follow across chats, such as your preferred response style. In Codex, these
personal instructions are stored in your global `AGENTS.md` file." On the
web: **Settings > Personalization > Base style and tone** for a personality,
which "changes its style and tone; it doesn't change its capabilities".
*Prompting* (see codex note): "Put preferences that should apply across
chats in **Settings > Personalization** as custom instructions."

## Memory

- "ChatGPT web uses ChatGPT memory, while local Codex clients use a separate
  local memory store and controls."
- Codex: "Local Codex memories are off by default." Turn on in the desktop
  app under **Settings > Personalization > Enable Codex memories**, or
  `[features] memories = true`. Per chat: `/memories`. Stored under
  `~/.codex` (`memories/` or `memories_v2/`).
- "Keep required team guidance in `AGENTS.md` or checked-in documentation.
  Treat memories as a helpful recall layer, not as the only source for rules
  that must always apply."
- "Codex skips active or short-lived sessions, redacts secrets from generated
  memory fields, and updates memories in the background".
- Web: "Manage ChatGPT memory from **Settings > Personalization**." Nothing
  more on ChatGPT (web) memory was readable: the Help Centre's memory FAQ
  returned HTTP 403.
- Computer History: "an opt-in macOS desktop feature that can turn activity
  across allowed apps and websites into memories and a timeline".

## AGENTS.md, the instruction file

- "Codex reads `AGENTS.md` files before doing any work."
- Order: the global file in `~/.codex` (`AGENTS.override.md`, else
  `AGENTS.md`), then each directory from the project root down to the
  current one, at most one file per directory. "Files closer to your current
  directory override earlier guidance because they appear later in the
  combined prompt."
- Size: "stops adding files once the combined size reaches the limit defined
  by `project_doc_max_bytes` (32 KiB by default)".
- Other names only by configuration: "Filenames not on this list are
  ignored for instruction discovery" (`project_doc_fallback_filenames`). So
  a `CLAUDE.md` is not read unless added there.
- "Codex rebuilds the instruction chain on every run".
- Check what loaded: `codex --ask-for-approval never "Summarize the current
  instructions."`
- `/init` "Generate an `AGENTS.md` scaffold for the current project"
  (slash-commands page).

Best practices, as quoted by the fetch tool: "A short, accurate `AGENTS.md`
is more useful than a long file full of vague rules." "When Codex makes the
same mistake twice, ask it for a retrospective and update `AGENTS.md`."
"Start with the basics, then add new rules only after you notice repeated
mistakes." Planning: "If the task is complex, ambiguous, or hard to describe
well, ask Codex to plan before it starts coding." "Toggle with `/plan` or
Shift+Tab." Reasoning effort: "Low for faster, well-scoped tasks"; "Medium or
High for more complex changes or debugging".
