# What to check each month

For the monthly check: read each address, compare against the guide's
"Last checked" line, and list what moved. The guide's volatile facts are all
in its section *The moving parts*. Every learn.chatgpt.com page has a
Markdown twin: add `.md` to the address. The full index is
<https://learn.chatgpt.com/llms.txt>.

| What | Address | What would change the guide |
|---|---|---|
| Changelog (apps and Codex CLI) | <https://learn.chatgpt.com/docs/changelog> | A new Codex CLI version, a model retired, a new default |
| Codex releases | <https://github.com/openai/codex/releases> | The CLI version in *The moving parts* |
| Models | <https://learn.chatgpt.com/docs/models.md> | Which model a paid plan should use; retirements (GPT-5.5 left Codex on 14 October 2026) |
| Pricing and limits for Work and Codex | <https://learn.chatgpt.com/docs/pricing.md> | Plan prices, models per plan, the five-hour message estimates |
| ChatGPT plans | <https://chatgpt.com/pricing> | Plan names, the Privacy row ("Content is used to train our models"); prices are filled in by script, so read it in a browser |
| AGENTS.md | <https://learn.chatgpt.com/docs/agent-configuration/agents-md.md> | File names read, size limit, order |
| Memories | <https://learn.chatgpt.com/docs/customization/memories.md> | Defaults, where the switches are |
| Projects | <https://learn.chatgpt.com/docs/projects.md> | Local projects, what a project can reach |
| Personalize (custom instructions) | <https://learn.chatgpt.com/docs/personalize.md> | Where custom instructions live |
| Prompting | <https://learn.chatgpt.com/docs/prompting.md> | The vendor's own advice the guide quotes |
| Best practices | <https://learn.chatgpt.com/guides/best-practices> (rendered by script) | `AGENTS.md` and planning advice |
| Non-interactive mode | <https://learn.chatgpt.com/docs/non-interactive-mode.md> | `codex exec` defaults (read-only sandbox) |
| Data controls (Help Centre) | <https://help.openai.com/en/articles/7730893-data-controls-faq>; <https://help.openai.com/en/articles/5722486-how-your-data-is-used-to-improve-model-performance> | Training default and switch. **Blocked to scripts (HTTP 403) on 11 November 2026**: read in a browser |
| Codex in the Help Centre | <https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex> | Model availability and limits per plan. Also blocked to scripts |

The learn.chatgpt.com pages carry no "updated" date; compare the text. The
Help Centre pages carry one.
