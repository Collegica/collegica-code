# The Notebook That Holds the Truth About Your Business

Research and worked example for the AI article of 2026-10-30
(`website/ai/business-notebook/`), a small-business guide to a single source
of truth that an AI assistant keeps. Written general first; a construction
version is planned (see the ISO 19650 section of
`notes/digital-twin-and-ssot.md`, which needs primary sources first).

| Folder or file | What it is |
|---|---|
| `notes/llm-wiki-and-okf.md` | Karpathy's LLM wiki (gist read in full), the OKF v0.2 spec (read in full), llms.txt, MCP, vendor grounding docs |
| `notes/digital-twin-and-ssot.md` | Definitions, Statistics Canada's AI-adoption figures, ISO 19650 (secondary), and what could not be read |
| `example/` | A fictional catering company: five sources, an `AGENTS.md` rulebook, the wiki Claude Code wrote from them, and `RUN.md` describing the run |

Owner's decisions: no "digital twin" in the title; title chosen by the
owner; keep it general, construction later.
