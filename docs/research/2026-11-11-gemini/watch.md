# What to check each month

For the monthly check: read each address, compare against the guide's "Last
checked" line, and list what moved. The guide's volatile facts are all in its
section *The moving parts*.

| What | Address | What would change the guide |
|---|---|---|
| Gemini app release notes | <https://gemini.google/release-notes/> | A new model, a new app, skills or memory changing |
| Plans and prices (CAD) | <https://gemini.google/subscriptions/> (fetch from Canada; region "Canada") | Prices, plan names, which model each plan gets, usage multiples |
| Google AI plans FAQ | <https://one.google.com/about/google-ai-plans/> | Model names per plan |
| Gems to skills | <https://support.google.com/gemini/answer/18560919> | The 17 November and 17 December 2026 dates; what skills can do (Drive files, sharing, Canvas) |
| Memory | <https://support.google.com/gemini/answer/16598469> | Where the switch is; what it needs |
| Instructions and remembered facts | <https://support.google.com/gemini/answer/16598625> | US-only limit; the 18-month limit |
| Privacy hub | <https://support.google.com/gemini/answer/13594961> | Training, human review, 72 hours, three years |
| Activity | <https://support.google.com/gemini/answer/13278892> | Keep Activity default; auto-delete periods |
| File uploads | <https://support.google.com/gemini/answer/14903178> | File count and size limits |
| Gemini CLI status | <https://github.com/google-gemini/gemini-cli> (README box), releases via the GitHub API | Whether personal accounts return |
| Code Assist consumer deprecation | <https://developers.google.com/gemini-code-assist/docs/deprecations/code-assist-individuals> | Anything new for individuals |
| Antigravity CLI | <https://github.com/google-antigravity/antigravity-cli> releases; <https://antigravity.google/docs/cli/gcli-migration> | Instruction-file handling, headless flags |
| Antigravity pricing | <https://antigravity.google/pricing> (built in the browser) | Free tier limits |

The help-centre pages carry no date except the privacy hub's "Last updated"
lines; compare the text. The release notes are dated `YYYY.MM.DD`.
