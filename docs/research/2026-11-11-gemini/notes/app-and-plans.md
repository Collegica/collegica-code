## Files

<https://support.google.com/gemini/answer/14903178> ("Upload & analyze files
in Gemini Apps"), read 2026-11-11:

- "You can add up to 10 (subject to availability) of any kind of supported
  file in the same prompt".
- "Each video can be up to 2 GB. All other supported file types can be up to
  100 MB."
- A code folder or GitHub repository: "up to 5,000 files and a maximum size of
  100 MB". "To add a code folder: click More Uploads Import Code Upload
  folder."
- Files from Drive need "Keep Activity on and connect Google Workspace to
  Gemini Apps".
- "There are rolling limits for how much you can upload and analyze files in
  a period of time."
